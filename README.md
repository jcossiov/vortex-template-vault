# 🌌 Vortex Templates Vault — Live Web App

Biblioteca interactiva y explorador de **466 plantillas UI de clase mundial**, dinamismos, efectos visuales (Framer Motion, Three.js, CSS Keyframes) y generador de prompts maestros de replicación para IA.

## 🚀 Acceso en Vivo
- **URL de Producción:** https://jcossiov.github.io/vortex-template-vault/
- **Templates Totales:** 466 plantillas catalogadas
- **Categorías:** 7 colecciones con carrusel deslizable
  - 🌐 Todas las Plantillas (466)
  - 🌑 Darks & Cyber Tech (48)
  - 🕊️ Limpios & Minimalistas (23)
  - 🔮 Raros & WebGL 3D (86)
  - 💻 Tecnológicos & SaaS (261)
  - 🛍️ E-Commerce & CRO (23)
  - 🏢 Agencias & Servicios (25)

## ✨ Características del Explorador
1. **Carrusel Deslizable:** Botones de navegación izquierda/derecha + scroll con trackpad + arrastre con mouse.
2. **Modal Inspector 5 Pestañas:**
   - 🎬 Efectos y Dinamismos exactos
   - 🏗️ Árbol de Componentes
   - 🎨 Tokens de Diseño (CSS / Tailwind)
   - 📋 Prompt Maestro con botón de copia en 1 clic y descarga JSON
   - ⚡ Generador "Replicar para mi Cliente" con reemplazo en vivo de marca, nicho y acento
3. **Filtros & Búsqueda Instantánea:** Filtrado por texto, autor, tags y categoría.
